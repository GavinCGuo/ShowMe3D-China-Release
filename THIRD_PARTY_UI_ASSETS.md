# Third-party UI assets

The V2 Stitch-to-SpatialUI implementation bundles the following Google assets locally so the PICO application does not depend on network font or icon loading at runtime:

- Nunito, Nunito Sans, and Quicksand from Google Fonts — SIL Open Font License 1.1.
- Material Symbols Outlined from Google Material Design Icons — Apache License 2.0.
- Screen-specific images exported from the user's existing Google Stitch project are project design assets supplied for this application.

Upstream sources:

- https://github.com/google/fonts
- https://github.com/google/material-design-icons
